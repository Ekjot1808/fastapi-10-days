# FastAPI DAY - 1

API : An API is a communication interface that allows two software applications to exchange data

FastAPI: Python Webframework used to build APIs
- High Performance
- Built in data validation using pydantic
- Supports Asynchronus Programming
- Python type hints


HTTPS Methods : HTTP methods tell the server what operation the client wants to perform.
- GET: Retrieve data 
- POST: Create data 
- PUT: Replace data
- PATCH: Partially Update data
- DELETE: Delete data
